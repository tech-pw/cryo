How the governor decides when a job runs

Workers don't pick work up on their own. Every job passes the governor's checks first, then gets a slot only where an engine has room right now.

Admitted

The job goes to the worker queue for that coordinator. The worker renders the plan, runs it, and writes the result to the audit log.

Deferred

A failed check usually defers the job and records why. With no free slot, it stays queued for the next governor wave. Adding workers never adds parallel rewrites.
