# CryoBench V2 -- protocol freeze
#
# The original freeze: the SHA-256 of the protocol and the controller scripts
# as they ran when the data was collected. These are the checksums that
# attest the protocol did not change while the benchmark ran. They match the
# internal repository, not the published tree.
#
# The published checksums: the same files after the internal identifiers were
# replaced with placeholders for publication. The scrub changed the bytes of
# three of the four files, so these differ from the originals.
#
# A reader who wants to check the published file matches the second block.
# A reader who wants to check provenance matches the first.
#
# The replacements: <benchmark-bucket>, <benchmark-cluster>, <node>, <home>,
# <internal-host>, <internal-domain>, and the benchmark namespace. The AWS
# region is not replaced -- it is public.
# No measured number was changed -- the analysis outputs regenerate
# byte-identically from the scrubbed data, which is what proves it.
