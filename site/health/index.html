Health and cost

A grade is a score with the deductions still attached.

The Scanner grades a table from stored metadata. It does not scan data files on the request path. Object storage is not an input.

What each operation projects

expire_snapshots

Projects bytes referenced only by snapshots the retention policy would drop — and only when no surviving snapshot still references the file.

remove_orphan_files

Projects bytes present in storage but referenced by no snapshot. Precise only on the scanner's opt-in listing tier; otherwise flagged as last-known.

optimize

Projects delete-file bytes merged away. Data bytes are rewritten, so the storage change is left to the later expiry projection.

optimize_manifests

Projects manifest and metadata bytes reclaimed by consolidation. Small in volume, big in plan-list latency.
