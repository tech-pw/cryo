The operator view

Four answers before the next run.

Observe the fleet, decide what is safe to run, watch it happen, and prove what changed.

01Observe

Which tables need care?

The Scanner grades every table from stored metadata — no live data scans on the hot path.

02Decide

What is safe to run?

The Planner emits an ordered plan. The Governor admits it only when Trino or Spark have headroom.

03Run

What is happening now?

Workers execute one table at a time. Failure on one table stays on that table — the run continues.

04Prove

What changed, exactly?

An audit row per run: table, operation, engine, duration, before/after. Stored, queryable, exportable.

The maintenance story

Compact first, then clean up.

See the guardrails →

A single run on one table walks the operations in a fixed order. Compaction creates new files; expiry removes old ones — so one pass reclaims the space its own compaction freed.
