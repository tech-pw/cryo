Quickstart

A local lake, then a scan.

Requires Docker, Python 3.12+, and Node 22+. Clone, start, seed, and open the UI. The demo catalog has intentional maintenance issues so you can see Cryo work.

Install

bash · cryo-local
$ git clone https://github.com/tech-pw/cryo.git $ cd Cryo $ make up … waiting for API and Postgres to be healthy $ make seed … creates demo Iceberg tables with intentional maintenance issues $ open http://localhost:5173

Clone

Clone the public repository. The default branch is stable.

Start

Start the local stack — API, Web UI, Postgres, Redis, and a demo Trino.

Seed

Create demo Iceberg tables with intentional maintenance issues — small files, stale manifests, expirable snapshots.

What runs locally

What you can do next

  • Open the Tables tab. The seeded tables will already show grades.
  • Open the Maintenance tab. The Scheduler has queued jobs.
  • Watch the run console. The Governor admits jobs as Trino has headroom.
  • Click any audit row to see the receipt: operation, engine, duration, before / after.

Cryo is pre-1.0. The launch-tier surface is scanner, planner, governor, Trino and Spark engines, presets, audit, and the run console. See architecture for the real component split.
