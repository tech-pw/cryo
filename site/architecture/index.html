Assignment

Component jobs

Scanner

The Scanner reads Sources and is the single source of truth for what shape every table is in. It never reads data files.

Planner

The Planner emits ordered operations and partition predicates, but no SQL strings. The engine renders the SQL.

Governor

The Governor decides whether and when a job may run. It probes live load, applies caps, and round-robins replicas.

Worker

A Worker executes one table's maintenance on one destination engine. Failure on that table is recorded; the run continues.
