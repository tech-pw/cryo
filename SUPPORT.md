# Support

## Questions and ideas

- Ask usage and design questions in [GitHub Discussions → Q&A](https://github.com/tech-pw/cryo/discussions/categories/q-a).
- Propose features in [Ideas](https://github.com/tech-pw/cryo/discussions/categories/ideas), and share what you built in [Show and tell](https://github.com/tech-pw/cryo/discussions/categories/show-and-tell).
- Report bugs in [GitHub Issues](https://github.com/tech-pw/cryo/issues).

## Policy

Support policy, channels, severity, and the diagnostic bundle are in [docs/SUPPORT_POLICY.md](docs/SUPPORT_POLICY.md).

Vulnerability reports follow [SECURITY.md](SECURITY.md). Do not open a public issue for those. No mailbox is published. GitHub Security Advisories return 404 while this repository is private.

Questions belong in GitHub Discussions after the repository is public. That page 404s until then.
